# 🎧 Spotify for Learning - MVP

## 🎯 Project Overview

**Spotify for Learning** is an AI-powered assistant that creates personalized, 5-minute educational snippets in a podcast format. Users can input their interests, and the system curates a playlist of short audio-based lessons — ideal for on-the-go learning during commutes, workouts, or breaks.

---

## 🚀 Tech Stack

- **Frontend**: TypeScript, CSS
- **AI Content Generation**: Gemini API (Free)
- **Text-to-Speech**: ElevenLabs
- **Audio Player**: HTML5 `<audio>` tag
- **Design**: Spotify-inspired (Green & Black Theme)
